# 🍋 Lemontree Hackathon Project

## 🛠 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Maps:** Mapbox GL JS

## 🚀 Getting Started
1. `npm install`
2. `npm run dev`

## 🤝 Contribution Rules
- **No pushing to `main`.**
- Create a feature branch: `git checkout -b feature/name`
- Open a Pull Request for review.
